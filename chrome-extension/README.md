# JPDF 크롬 확장 프로그램

데스크톱 앱과 같은 무손실 엔진을 JavaScript로 옮긴 것입니다. 모든 처리는 브라우저 안에서만 이루어지고,
파일은 어디로도 전송되지 않습니다.

## 기능

* **변환 페이지** (확장 아이콘 클릭): 이미지를 끌어다 놓고 순서·페이지 크기·여백·DPI를 정해 `.jpdf`/`.pdf`로 저장.
  JPEG은 원본 바이트 그대로, PNG는 압축 데이터 그대로(알파는 SMask) 들어가며, GIF·WebP·BMP·AVIF 등은
  브라우저로 디코딩해 무손실(Flate)로 저장합니다.
* **JPDF / PDF 열기**: `.jpdf`를 놓으면 "PDF로 보기"(크롬 내장 PDF 뷰어) / "이미지로 보기"(갤러리, 개별 다운로드,
  ZIP으로 모두 저장)를 전환할 수 있습니다. JPEG은 바이트 그대로, PNG는 픽셀 그대로 꺼내며, 원본과 SHA‑256이
  일치하면 배지로 표시합니다. 다른 도구가 만든 일반 PDF의 이미지도 꺼낼 수 있습니다.
* **우클릭 메뉴**: 웹페이지 이미지 위에서 "이 이미지를 JPDF/PDF로 저장", "JPDF 변환 페이지에 추가".
  페이지 빈 곳에서 "이 페이지의 이미지 모두 모아 PDF로…"를 누르면 이미지 목록에서 골라 한 번에 변환합니다.

## 설치 (압축 해제된 확장 프로그램 로드)

1. 크롬 주소창에 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `chrome-extension` 폴더를 선택합니다.
3. 툴바의 퍼즐 아이콘에서 JPDF를 고정해 두면 편합니다.

## 권한 설명

| 권한 | 이유 |
|---|---|
| `contextMenus` | 우클릭 메뉴 항목 |
| `downloads` | 변환 결과를 정해진 이름으로 저장 |
| `scripting`, `activeTab` | "이 페이지의 이미지 모두 모으기"를 위해 현재 탭의 `<img>` 목록을 읽음 (사용자가 메뉴를 눌렀을 때만) |
| `storage` | 출력 옵션 저장, 탭 간 작업 전달 (`storage.session`) |
| `notifications` | 우클릭 저장이 실패했을 때 알림 |
| 호스트 권한 `<all_urls>` | 우클릭한 이미지·모은 이미지의 바이트를 가져오기 위해 (크로스 오리진 fetch). 설치 시 "모든 사이트의 데이터를 읽고 변경" 경고가 뜨는 이유입니다. 이미지 바이트를 읽는 것 외에 페이지를 건드리지 않습니다. |

## 파일 구성

```
manifest.json      MV3 매니페스트
background.js      서비스 워커 (우클릭 메뉴, 이미지 수집, 다운로드)
app.html/js/css    변환·열기 페이지
core/jpdf.js       엔진 (JPEG/PNG 파서, PNG 코덱, PDF 작성기, 객체 스캔 기반 추출기, ZIP)
icons/             아이콘
tests/             Node 상호운용 도구, Playwright 검증 스크립트
```

## 테스트

* 데스크톱 저장소 루트에서 `python -m pytest tests/test_js_interop.py` — JS가 만든 파일을 Python이 읽고, Python이 만든 파일을 JS가 읽는지(바이트/픽셀 동일), EXIF 방향 8종의 렌더링 일치, A4 배치를 확인합니다 (Node 필요).
* `NODE_PATH=$(npm root -g) node tests/ext_playwright.mjs <fixtures> <out> [http://127.0.0.1:8765]` — 실제 Chromium에 확장을 로드해 변환·다운로드·열기·ZIP·서비스 워커 경로를 검증하고 스크린샷을 남깁니다 (Playwright 필요).

## 웹 스토어 출시에 대해

출시하려면 Chrome 웹 스토어 개발자 계정(1회 등록비, 본인 결제)과 심사가 필요합니다. `dist/` 폴더의 zip이 그대로
업로드용 패키지입니다. `<all_urls>` 호스트 권한은 심사에서 사유를 물어보므로, 위 권한 설명을 그대로 적으면 됩니다.
